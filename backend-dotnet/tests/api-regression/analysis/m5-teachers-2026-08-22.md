# Evidencia M5 — legajo, documentos, cargos y asignaciones docentes

Fecha: 2026-08-22  
Entorno: API `http://localhost:8010`, SQL Server `localhost:1434`, base aislada `AcademiaDigitalE2E`.

## Alcance validado

- CRUD administrativo de `/api/v1/teachers` con permisos 401/403.
- Usuario activo con rol `Profesor`, número de empleado normalizado y conflictos 409 por usuario o número repetido.
- Datos de domicilio, contacto de emergencia y actualización del legajo.
- Baja lógica idempotente con fecha, actor y motivo; exclusión del listado activo y presencia en la consulta histórica.
- Upgrade de migraciones hasta `AddTeacherProfilesAndSoftDelete`, diez columnas nuevas e índice único `IX_Teachers_user_id`.
- Alta, listado y revisión Admin de documentos docentes con permisos 401/403 y contrato Zod.
- Versionado por tipo normalizado, expiración automática de la versión anterior, aprobación/rechazo auditado y observación obligatoria al rechazar.
- CRUD lógico de cargos/vacantes por materia, comisión, ciclo, semestre y tipo.
- Asignación y finalización serializable, con historial append-only y sincronización de `TeacherId/IsVacant` para compatibilidad.
- Consulta propia resuelta por usuario autenticado, incluyendo aislamiento entre dos profesores y rechazo 401/403.
- Upgrade hasta `20260822214829_AddTeacherDocumentsPositionsAndAssignments`, validando documentos, cuatro FKs de asignaciones, unicidad del cargo vigente, constraint de ocupación y backfill de cargos heredados.
